## 3. Inc.2 機能スコープ

### 3.1 SDP §3.2 確定スコープ

**Inc.2 = アラーム管理:** 閉塞検知、気泡検知、薬液切れ検知、バッテリ低下、アラーム通知・確認・消音

| カテゴリ | 含む | 含まない(Inc.3 / Inc.4 申し送り) |
|---------|------|----------------------------|
| 異常検知 | 閉塞 / 気泡 / 薬液切れ / バッテリ低下 | 流量乖離(Inc.4)、誤薬剤(Inc.3) |
| アラーム I/F 本実装 | ARCH-007 Alarm Reporter Stub I/F の本実装、IEC 60601-1-8 優先度分類(高/中/低)、テクニカル / 生理アラーム区分、確認・消音操作 | 履歴の永続化(Inc.4 ロギング)、UI 操作(Inc.4 対話 UI)、用量計算連動(Inc.3) |
| 仮想 HW イベント注入 | UNIT-002.3 Event Injection Stub の no-op 解除(`OCCLUSION` / `AIR_BUBBLE` / `RESERVOIR_EMPTY` を Pump へ伝播 + `BATTERY_LOW` enum 追加) | — |
| 状態機械拡張 | アラーム発報経路 + 確認 / 消音状態 | — |

### 3.2 範囲外として明示するもの

以下は SDP §3.2 で別 Inc に割り当てられているため、Inc.2 では実装しない:

- 用量計算 / ボーラス / 段階投与スケジュール → Inc.3
- 注入履歴 / アラーム履歴の永続化 → Inc.4(ロギング ARCH-006 本実装)
- 対話 UI(start / stop / 設定入力) → Inc.4
- 流量乖離検知 → Inc.4

1. **A → B → C → D → E** は IEC 62304 §5.2 → §7 → §5.3 → §5.4 の積み上げ順を踏襲(Inc.1 の Step 11 → 12 → 12c → 13 → 14 と同形)
